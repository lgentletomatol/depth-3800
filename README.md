# 수심 3800

수심 3,800m에 가라앉은 채굴 지원선 안에서, 헬멧 라이다만으로 탈출 수단을 찾는 1인칭 공포게임.

- 잠수할 때마다 괴물(3종 중 하나), 부품 위치, 막힌 문이 바뀐다.
- 키보드와 마우스가 필요하다. 헤드폰 권장.
- 한 판 15~25분.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시점 |
| 좌클릭 | 집중 스캔 (누르고 있기) |
| 우클릭 | 전방위 펄스 |
| 휠 | 빔 폭 |
| Shift | 달리기 (소음, 산소 소모) |
| C | 살금살금 걷기 |
| F | 미끼 비콘 투척 |
| E | 문 · 줍기 · 숨기 · 설치 |
| Tab | 선내 지도 |
| Esc | 일시정지 · 기록 |

## 실행

`index.html` 파일 하나로 동작한다. 빌드 과정은 없다.
